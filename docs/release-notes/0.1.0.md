The first release of Freezer, a multilingual Flutter app for keeping track of what is in your freezer. Everything stays on the phone: the Android build has no network permission, the database is encrypted with SQLCipher, and data only leaves the device through the app's own encrypted backup.

## What's in 0.1.0

**Foundation** ([#2](https://github.com/jcosmith/freezer/pull/2))
Workspace of core packages and one package per feature, the app shell with the home dashboard, routing and the feature module contract, and CI checks for architecture rules, privacy and generated code.

**Freezers and inventory** ([#3](https://github.com/jcosmith/freezer/pull/3))
Freezers with drawers you can name, reorder and archive, a translated product catalog with a product editor, and the inventory: put items in, take them out, undo.

**Configuration, onboarding and languages** ([#4](https://github.com/jcosmith/freezer/pull/4))
The Config tab, a first-start onboarding flow and an in-app language choice.

**Backup, restore and CSV export** ([#5](https://github.com/jcosmith/freezer/pull/5))
Encrypted backups, a staged restore that checks a backup before replacing anything, and CSV export.

**Storage reminders** ([#6](https://github.com/jcosmith/freezer/pull/6))
Reminders for goods stored a long time, an "eat soon" dashboard card and a backup reminder notification.

**Restock and shopping list** ([#7](https://github.com/jcosmith/freezer/pull/7))
Restock rules per product that put items on a shopping list when stock runs low.

**Insights** ([#8](https://github.com/jcosmith/freezer/pull/8), [#9](https://github.com/jcosmith/freezer/pull/9))
An Insights tab with charts of your habits and a shared filter, a details screen with saved views, and a "Runs out in" estimate for restock.

**Item pictures** ([#10](https://github.com/jcosmith/freezer/pull/10), [#11](https://github.com/jcosmith/freezer/pull/11))
Optional photos for items, stored encrypted on the device, and carried inside backups with a "without pictures" option.

**Barcode scanning** ([#12](https://github.com/jcosmith/freezer/pull/12), [#13](https://github.com/jcosmith/freezer/pull/13))
Optional, off by default: learn product barcodes, scan to add or remove stock, and scan several groceries in a row to put them away at once.

## Installing

Download `freezer-0.1.0.apk` below and install it on an Android phone. Its SHA-256 checksum is in `freezer-0.1.0.apk.sha256`. The APK is signed with the Android debug key for now. Moving to a proper release key later will require uninstalling the app, which deletes its data, so export a backup before that update.
