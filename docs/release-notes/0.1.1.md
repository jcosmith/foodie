Fixes and small improvements from the first days of use, and the app's own icon.

## What's in 0.1.1

**Backup and restore no longer turn the screen black** ([#23](https://github.com/jcosmith/freezer/pull/23), fixes #16)
Saving or restoring a backup from the Config tab closed the tab instead of the progress dialog, leaving a black screen. The dialog now closes properly when the work is done.

**New items go into the product's usual drawer** ([#24](https://github.com/jcosmith/freezer/pull/24), fixes #17)
A product can have a default drawer, set in the product editor. Adding the product preselects that drawer, or the drawer it went into last time if it has none.

**"Overdue" once the maximum freezing time is reached** ([#25](https://github.com/jcosmith/freezer/pull/25), fixes #18)
Food stored longer than its maximum time shows an "✕ Overdue" badge instead of "Eat now".

**"Eat first" sorting** ([#26](https://github.com/jcosmith/freezer/pull/26), fixes #19)
The Freezer tab's "Sort by age" became "Eat first": items are sorted by how soon they should be eaten, using each item's maximum storage time, rather than by how long they have been frozen.

**Collapsible drawers** ([#27](https://github.com/jcosmith/freezer/pull/27), fixes #20)
Tap a drawer's header in the Freezer tab to fold it away; "Expand all" and "Collapse all" open or close every drawer at once. Inside each drawer, items are sorted with the ones to eat first at the top.

**Pictures as product icons** ([#28](https://github.com/jcosmith/freezer/pull/28), fixes #21)
In the product editor, "Choose a picture" picks any image file as the product's icon instead of an emoji. The app scales and converts it itself and keeps it inside the encrypted database, so it is part of every backup.

**A new app icon** ([#29](https://github.com/jcosmith/freezer/pull/29), fixes #22)
The launcher icon is now an open freezer full of food, with a round adaptive icon on Android 8 and later.

## Installing

Download `freezer-0.1.1.apk` below and install it on an Android phone. Its SHA-256 checksum is in `freezer-0.1.1.apk.sha256`. The database is upgraded automatically when the app first starts.

**Updating from 0.1.0: save a backup first.** The APK is still signed with a temporary debug key that may differ between releases. If Android refuses to install it over 0.1.0 ("App not installed" or a conflicting package), uninstall 0.1.0, install 0.1.1 and restore the backup from the Config tab. Uninstalling deletes the app's data, so make sure the backup is saved somewhere outside the app, such as Downloads.
