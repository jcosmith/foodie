# Third-party packages the app ships with (runtime dependencies of
# apps/freezer_app, transitively). Each entry was reviewed for network access.
# The architecture check fails when a package appears that is not listed here,
# so adding a dependency is always a deliberate, reviewed step.
#
# Notes on entries that look surprising:
# - http: required by `timezone`, but only its web-only library
#   (package:timezone/browser.dart) imports it; the app never does, the
#   architecture check rejects network imports in our code, and the release
#   Android build has no INTERNET permission.
# - flutter_test and its leak_tracker packages: listed as a regular dependency
#   by flutter_riverpod; never imported by app code.
# - hooks, code_assets, native_toolchain_c: build hooks that bundle SQLCipher
#   at build time; they do not run inside the app.
# - file_picker and its platform packages: only the system save and open
#   dialogs for backups and CSV files (feature_data_portability) and the open
#   dialog for product icon pictures (feature_product_catalog); no network
#   permission or code. Desktop and web variants are never used on phones.
# - fl_chart: chart rendering for the chart kit in core_design_system
#   (decision D7); pure Dart drawing, no network code. Only the design system
#   may depend on it.
# - image, archive, posix: pure Dart decoding and JPEG encoding of pictures in
#   core_media_storage (archive is image's codec helper; posix only reads
#   file permissions). No network code.
# - cryptography: AES-GCM for picture files (decision D11), pure Dart.
# - image_picker and its platform packages (file_selector_*, mime,
#   flutter_plugin_android_lifecycle): the system camera and photo picker
#   for feature_item_pictures. They hand back a local file; no network
#   permission or code. Desktop and web variants are never used on phones.
# - mobile_scanner: the barcode decoder (decision D12), only in
#   feature_barcode_scanning. Android uses ML Kit with the bundled model
#   (com.google.mlkit:barcode-scanning, the plugin's default; the unbundled
#   Play services variant that downloads the model is never enabled), iOS
#   uses Apple's Vision framework. Its web variant, which loads a decoder
#   script from a CDN, is never used on phones. The release manifest
#   removes INTERNET and ACCESS_NETWORK_STATE in case ML Kit declares them.
